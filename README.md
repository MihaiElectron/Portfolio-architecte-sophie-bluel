# Sophie Bluel

## Description

Sophie Bluel est un projet réalisé dans le cadre de la formation Développeur Intégrateur Web d'OpenClassrooms.

L'objectif était de transformer une page statique en site dynamique en JavaScript, en communiquant avec une API REST fournie. Le projet comprend l'affichage dynamique des travaux d'une architecte d'intérieur, la gestion d'un espace administrateur, l'authentification, ainsi qu'une modale permettant d'ajouter et de supprimer des projets.

## Objectifs

* Récupérer des données depuis une API.
* Afficher dynamiquement les projets dans le DOM.
* Créer une page de connexion administrateur.
* Gérer l'authentification avec un token.
* Développer une modale d'administration.
* Ajouter et supprimer des projets sans rechargement de page.

## Lancer le projet

1. Cloner le dépôt.
2. Installer les dépendances du back-end avec `npm install`.
3. Lancer le back-end avec la commande indiquée dans le README du dossier serveur.
4. Ouvrir le front-end dans un navigateur.
5. Utiliser les identifiants fournis dans le projet pour tester le mode administrateur.
